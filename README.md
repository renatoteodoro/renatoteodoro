## Projetos selecionados

### [Arquitetura com Hermes Agent, MCP e aprovação humana](https://github.com/renatoteodoro/hermes-agent-architecture-case)

Estudo de caso sanitizado de uma arquitetura exercitada em ambiente hospedado: API Server protegido, publicação HTTPS, integração MCP com 21 ferramentas, sessões restritas por guardrails e fluxo de aprovação humana antes do arquivamento da entrega.

### [Sparzap](https://github.com/renatoteodoro/sparzap)

Plataforma de automação de vendas e atendimento no WhatsApp. Usa Django, Celery, Redis e Evolution API, com CRM, campanhas, webhooks, isolamento por usuário e testes automatizados.

### [WathsBotApp](https://github.com/renatoteodoro/WathsBotApp)

Assistente RAG para WhatsApp com FastAPI, LangChain, ChromaDB e Redis. Inclui ingestão de conteúdo, busca semântica, memória de conversa, agrupamento de mensagens e atualização periódica da base com Playwright.

### [Beton Dekor](https://github.com/renatoteodoro/beton-dekor-deploy)

Aplicação Django entregue para um cliente do setor de construção civil. Integra htmx, PostgreSQL, Cloudinary e Docker. [Aplicação publicada](https://betondekor.com.br/).

### [ADA](https://github.com/renatoteodoro/ADA)

Protótipo de hackathon desenvolvido em equipe. Combina Django, GPT-4o-mini, Whisper, Text-to-Speech, Playwright e VLibras para atendimento por texto e voz. O deploy está pausado; o código permanece como registro técnico do protótipo.

### [Portfólio com chatbot](https://github.com/renatoteodoro/portfolio)

Portfólio em Django com chatbot conectado à OpenAI API, apresentação dos projetos e página pública em produção.
